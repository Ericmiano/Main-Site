# AAK — Architectural Association of Kenya

Marketing site for the Architectural Association of Kenya, built with TanStack Start (React, SSR, file-based routing) and Tailwind CSS.

## Development

Requires Node.js.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build (outputs to `.output/`)
- `npm run preview` — preview the production build
- `npm run lint` — ESLint
- `npm run format` — Prettier
